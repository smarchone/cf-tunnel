Demo your local services.
One link. Free.

tl;drSend friends demo.you.workers.dev once. While your laptop runs online.sh, they log in and see your localhost. When you stop it, they see AFK.

The problem
  • Your app works on localhost. Nobody else can see it.
  • Quick tunnels hand out a new random URL every start. You resend it every time.
  • Anyone with that URL gets in. Close the lid and it just errors.
The fix
Permanent link

The URL never changes.

A Cloudflare Worker is the front door and follows each new tunnel for you. No domain, no card.

Friends only

A password per person.

Login happens at the Worker. The raw tunnel URL is useless without a secret only the Worker has.

Online = running

Ctrl-C and you're AFK.

One script starts everything and tears it down. Visitors get a clean AFK page, not an error.

friend→demo.you.workers.dev→login→tunnel→nginx→localhost:3000

Get started · ~1 min

needs Docker Desktop, Node and a free Cloudflare account
$ git clone https://github.com/smarchone/cf-tunnel && cd cf-tunnel
$ ./scripts/init-env.sh          # secret for the Worker ↔ laptop handshake
$ ./scripts/add-user.sh alice    # one per friend, password ≥ 12 chars
$ npx wrangler login             # free Cloudflare account
$ ./scripts/deploy-worker.sh     # prints your permanent link
  → https://demo.you.workers.dev
$ ./scripts/online.sh            # online while it runs · Ctrl-C = AFK
Expose a service

One file per service.

# nginx/templates/services/app.conf.template
location /app/ {
  proxy_pass http://host.docker.internal:3000/;
}

Then restart online.sh. Paths you don't list return 404.

What visitors see

Always a clear answer.

  • laptop offline → AFK
  • wrong password → 401
  • right password → your app
  • raw tunnel URL → 403
